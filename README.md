# Paradise Nursery Shopping Application

An online plant shop e-commerce web application where users can browse houseplants, view detailed plant descriptions, add plants to a shopping cart, adjust quantities, and calculate total costs.

## Project Overview
**Paradise Nursery Shopping Application** is built using React, Vite, and Redux Toolkit. It provides an intuitive, responsive user experience for shopping indoor houseplants, categorized by air purifying, aromatic, and medicinal plants.

## Features
- **Landing Page**: Welcome screen with company mission statement, About Us section, and a "Get Started" button.
- **Product Listing**: Plants grouped into distinct categories (Air Purifying, Aromatic Fragrant, Insect Repellent, Medicinal, Low Maintenance) with 6 unique houseplants per category, featuring images, descriptions, prices, and dynamic "Add to Cart" buttons.
- **Navigation Bar**: Persistent header showing links to Home, Plants, and Cart, along with an interactive shopping cart icon displaying total item count in real-time.
- **Shopping Cart**: Full cart management including increment/decrement of quantities, item deletion, per-plant subtotal, total cart price calculation, Checkout button with "Coming Soon" notification, and "Continue Shopping" navigation.

## Technologies Used
- React 18
- Redux Toolkit (@reduxjs/toolkit & react-redux)
- Vite
- CSS3 / Flexbox / Grid
